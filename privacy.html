นโยบายความเป็นส่วนตัว

สำหรับบริการ Shop อย่างมั่นใจ
ปรับปรุงล่าสุด: 28 กันยายน 2026

นโยบายความเป็นส่วนตัวฉบับนี้อธิบายวิธีที่ Shop อย่างมั่นใจ เก็บ ใช้ ประมวลผล และปกป้องข้อมูลเมื่อผู้ใช้งานใช้บริการของเรา หรือเชื่อมต่อบริการกับแพลตฟอร์มของบุคคลที่สาม

1. ข้อมูลที่อาจได้รับหรือประมวลผล

ขึ้นอยู่กับฟังก์ชันที่ผู้ใช้งานเลือกใช้ ระบบอาจได้รับหรือประมวลผล ข้อมูลที่เกี่ยวข้องกับบัญชีผู้ใช้งาน ข้อมูลสินค้า เนื้อหา วิดีโอ รูปภาพ เสียง คำบรรยาย และข้อมูลที่จำเป็นต่อการทำงานของบริการ

เมื่อผู้ใช้งานเชื่อมต่อบัญชีจากแพลตฟอร์มภายนอก ระบบอาจได้รับข้อมูลที่แพลตฟอร์มนั้นอนุญาตให้เข้าถึง ตามสิทธิ์ที่ผู้ใช้งานได้ให้ความยินยอมไว้

2. ข้อมูลจาก TikTok

หากผู้ใช้งานเลือกเชื่อมต่อบัญชี TikTok Shop อย่างมั่นใจ อาจได้รับข้อมูลที่ TikTok อนุญาต ผ่านระบบการยืนยันตัวตนและ API ของ TikTok ตามขอบเขตสิทธิ์ที่ผู้ใช้งานอนุญาต

ข้อมูลดังกล่าวอาจรวมถึงข้อมูลที่จำเป็นสำหรับ การตรวจสอบบัญชีผู้สร้างเนื้อหา การเตรียมเนื้อหา และฟังก์ชันการเผยแพร่ที่ผู้ใช้งานร้องขอ

Shop อย่างมั่นใจ จะไม่ขอสิทธิ์เข้าถึงข้อมูลเกินกว่าที่จำเป็น สำหรับฟังก์ชันที่ผู้ใช้งานเลือกใช้งาน

3. Access Token และข้อมูลการยืนยันตัวตน

เมื่อระบบต้องใช้ Access Token หรือข้อมูลการยืนยันตัวตน เพื่อเชื่อมต่อบริการภายนอก ข้อมูลดังกล่าวจะใช้เพื่อดำเนินการ ตามคำสั่งที่ผู้ใช้งานอนุญาตเท่านั้น

ระบบจะพยายามจัดเก็บข้อมูลการยืนยันตัวตนด้วยมาตรการที่เหมาะสม และไม่แสดง Access Token ต่อสาธารณะ

4. วัตถุประสงค์ในการใช้ข้อมูล

ข้อมูลอาจถูกใช้เพื่อให้บริการ เช่น การสร้างและจัดเตรียมเนื้อหา การสร้างวิดีโอ เสียง และคำบรรยาย การตรวจสอบคุณภาพของเนื้อหา การเชื่อมต่อกับบริการภายนอก และการดำเนินการตามคำสั่งของผู้ใช้งาน

ข้อมูลอาจถูกใช้เพื่อรักษาความปลอดภัย ตรวจสอบข้อผิดพลาด ป้องกันการใช้งานที่ไม่เหมาะสม และปรับปรุงความเสถียรของระบบ

5. การเผยแพร่เนื้อหา

ระบบจะไม่ถือว่าการสร้างวิดีโอหรือเนื้อหา เป็นการอนุญาตให้เผยแพร่โดยอัตโนมัติในทุกกรณี

การเผยแพร่เนื้อหาขึ้นอยู่กับการอนุญาตของผู้ใช้งาน สถานะบัญชี การตั้งค่าที่เกี่ยวข้อง และข้อกำหนดของแพลตฟอร์มปลายทาง

6. การแบ่งปันข้อมูลกับบุคคลที่สาม

ระบบอาจส่งข้อมูลไปยังบริการภายนอก เมื่อจำเป็นต่อการทำงานของฟังก์ชันที่ผู้ใช้งานเลือกใช้ เช่น บริการสร้างเนื้อหา การประมวลผลสื่อ หรือแพลตฟอร์มที่ผู้ใช้งานต้องการเชื่อมต่อ

การประมวลผลข้อมูลโดยบริการภายนอก อาจอยู่ภายใต้นโยบายความเป็นส่วนตัว และข้อกำหนดของผู้ให้บริการแต่ละราย

7. การเก็บรักษาข้อมูล

เราจะเก็บข้อมูลเท่าที่จำเป็นสำหรับการให้บริการ การรักษาความปลอดภัย การแก้ไขปัญหา หรือการปฏิบัติตามข้อกำหนดที่เกี่ยวข้อง

ระยะเวลาการเก็บรักษาอาจแตกต่างกันตามประเภทของข้อมูล ฟังก์ชันที่ใช้งาน และข้อกำหนดของบริการที่เชื่อมต่อ

8. ความปลอดภัยของข้อมูล

เราใช้มาตรการทางเทคนิคและการจัดการที่เหมาะสม เพื่อช่วยลดความเสี่ยงจากการเข้าถึง การเปิดเผย การเปลี่ยนแปลง หรือการสูญหายของข้อมูลโดยไม่ได้รับอนุญาต

อย่างไรก็ตาม ไม่มีระบบอินเทอร์เน็ตหรือระบบจัดเก็บข้อมูลใด ที่สามารถรับประกันความปลอดภัยได้อย่างสมบูรณ์

9. สิทธิของผู้ใช้งาน

ผู้ใช้งานสามารถยกเลิกการเชื่อมต่อบัญชีภายนอก หรือเพิกถอนสิทธิ์การเข้าถึง ตามเครื่องมือและวิธีการที่แพลตฟอร์มนั้นกำหนด

ผู้ใช้งานสามารถติดต่อเราเพื่อสอบถามเกี่ยวกับข้อมูล หรือขอให้ตรวจสอบ แก้ไข หรือลบข้อมูล ตามที่กฎหมายและข้อกำหนดที่เกี่ยวข้องอนุญาต

10. การยกเลิกสิทธิ์ TikTok

ผู้ใช้งานสามารถยกเลิกการอนุญาตให้ Shop อย่างมั่นใจ เข้าถึงบัญชี TikTok ได้ผ่านการตั้งค่าหรือเครื่องมือ ที่ TikTok จัดเตรียมไว้

เมื่อสิทธิ์ถูกยกเลิก ฟังก์ชันที่ต้องใช้การเชื่อมต่อดังกล่าว อาจไม่สามารถทำงานต่อได้

11. เด็กและผู้เยาว์

บริการนี้ไม่ได้ออกแบบมาเพื่อเก็บข้อมูลส่วนบุคคล จากเด็กหรือผู้เยาว์โดยเจตนา ผู้ใช้งานควรปฏิบัติตามข้อกำหนดด้านอายุ ของแพลตฟอร์มและกฎหมายที่เกี่ยวข้อง

12. บริการของบุคคลที่สาม

Shop อย่างมั่นใจ อาจเชื่อมต่อกับบริการของบุคคลที่สาม ซึ่งมีนโยบายความเป็นส่วนตัวของตนเอง เราแนะนำให้ผู้ใช้งานอ่านนโยบายของบริการเหล่านั้นด้วย

13. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายความเป็นส่วนตัวฉบับนี้ เมื่อบริการหรือข้อกำหนดที่เกี่ยวข้องมีการเปลี่ยนแปลง โดยจะแสดงวันที่ปรับปรุงล่าสุดไว้บนหน้านี้

14. ข้อกำหนดการให้บริการ

การใช้งาน Shop อย่างมั่นใจ ยังอยู่ภายใต้ ข้อกำหนดการให้บริการ ของเรา

15. การติดต่อ

หากมีคำถามเกี่ยวกับนโยบายความเป็นส่วนตัว หรือการจัดการข้อมูล สามารถติดต่อผู้ดูแล Shop อย่างมั่นใจ ผ่านช่องทางติดต่อที่เผยแพร่บนเว็บไซต์ของบริการ
